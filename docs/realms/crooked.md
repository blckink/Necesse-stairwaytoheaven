# Crooked Beyond

Status: IMPLEMENTED, awaiting player confirmation. The realm uses existing mod
art and literal vanilla-resource paths only; no new pixel art was generated.

## Registered content

| kind | ids |
|---|---|
| level | `crooked2` / `crookedlevel` |
| biomes | `stripedwaste`, `spiralfields`, `checkerworks` |
| tiles | `crookedstripetile`, `spiralsoiltile`, `violetmudtile`, `checkerstonetile`, `wrongwaytile`, `spilltile` |
| objects | `spiraltree`, `eyeballshrub`, `screamingflower`, `stripedmushroom`, `bentgrass`, `bentlantern`, `crookedclock`, `longchair`, `groundwindow`, `teethrock`, `crookedcrate`, `crookeddoordown`, `crookeddoorup` |
| mobs | `doormimic`, `tongueplant`, `stripebeetle`; existing `crookedgolem`, `rarecrookedgolem`, `crookedarmadillo` also spawn here |
| items | `oddwood`, `warpresin`, `strangefabric`, `eyeseed`, `stripedshell`, `realityshard` |

## Borrowed visual sources

| what it is | source path | what it stands in for |
|---|---|---|
| terrain | `tiles/ascendedgrowth`, `tiles/ascendedcorruption`, `tiles/deepstonetiledfloor`, `tiles/ascendedvoid` | Spiral Soil, Violet Mud, Checker Stone and Wrong-Way ground |
| liquid | vanilla liquid texture selected by `SpillTile` | the Spill between islands |
| flora | `objects/burnedbush`, `voidtrap`, `glowcoral`, `mushroom`, `witheredgrass` | Spiral Tree, Eyeball Shrub, Screaming Flower, Striped Mushroom and Bent Grass |
| structures | `objects/voidflame`, `boneclock`, `bonechair`, `voidcube`, `smallrunestone` | Bent Lantern, Crooked Clock, Long Chair, Ground Window and Teeth-Rock |
| hostile bodies | `mobs/mimic`, `mobs/dryadsentinel` | Door Mimic and Tongue Plant |
| critter body | `mobs/scorpion` | Stripe Beetle |
| item icons | `items/deadwoodlog`, `bioessence`, `clothscraps`, `crystalessence`, `crystallizedskull`, `ascendedshard` | the six Crooked materials in registration order |
| doorway | existing mod `objects/veilrift`, `objects/veilriftup` | the two Crooked travel doors |
| stripe ground | existing mod `tiles/beetlefreak` | Crooked Stripe terrain |

## Deferred

- Mr. Knott and the Architect: NPC/boss chapters need their own gameplay pass.
- Reality Stitcher and the placeable Crooked building family: no suitable complete
  borrowed station family is wired yet.
- Long-Legged Chicken and Crooked Goat: explicitly excluded by the handoff's
  no-livestock rule; vanilla bodies would not convey their designs.
- Custom realm art: all entries above remain on the player's later replacement list.
